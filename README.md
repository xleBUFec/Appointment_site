# BLADE & CO. | Премиум Барбершоп (Онлайн Запись + Supabase)

Современный и стильный веб-сайт онлайн-записи на стрижку и моделирование бороды с интеграцией с базой данных **Supabase**.

---

## 🚀 Особенности

- ✂️ **Интерактивный 4-шаговый мастер бронирования**:
  1. **Выбор услуги** (мужская стрижка, моделирование бороды, комплексные пакеты, СПА-уход) с фильтрацией по категориям, ценами и длительностью.
  2. **Выбор барбера** (карточки мастеров с фото, стажем, рейтингом, специализацией или опция «Любой свободный мастер»).
  3. **Выбор даты и времени** (календарная лента на 14 дней + слоты утро / день / вечер).
  4. **Контактные данные и подтверждение** (имя, валидация телефона, email, комментарий).
- ⚡ **Два режима работы**:
  - **Supabase**: Сохранение бронирований, чтение барберов и услуг в реальном времени.
  - **Демо-режим (Local Fallback)**: Работает сразу «из коробки» без обязательной настройки Supabase.
- ⚙️ **Встроенный модальный конфигуратор Supabase**: Ввод `Project URL` и `Anon Key` прямо из интерфейса с проверкой подключения в 1 клик.
- 📋 **Журнал всех записей**: Просмотр списка созданных броней, фильтрация/поиск по имени, номеру телефона, подсчет выручки и отмена записи.
- 💎 **Премиум-дизайн**: Тёмная благородная тема, золотые акценты, шрифты *Playfair Display* & *Inter*, адаптивность для мобильных телефонов.

## 🛠 Запуск проекта

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте в браузере ссылку, показанную в терминале (обычно `http://localhost:5173`).

---

## 🗄 Настройка Supabase

1. Создайте проект на [Supabase](https://supabase.com).
2. Откройте вкладку **SQL Editor** и вставьте код из файла [`supabase_schema.sql`](./supabase_schema.sql), затем нажмите **Run**.
3. Перейдите в **Project Settings → API** и скопируйте:
   - `Project URL`
   - `anon / public` key
4. Вставьте их либо в файл `.env`:
   ```env
   VITE_SUPABASE_URL=https://ваш-проект.supabase.co
   VITE_SUPABASE_ANON_KEY=ваш-публичный-anon-ключ
   ```
   Либо нажмите кнопку **«Демо / Подключить Supabase»** прямо в шапке сайта и сохраните ключи.
